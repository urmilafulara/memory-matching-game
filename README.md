# Memory Matching Game

An interactive browser-based memory matching game developed using HTML, CSS, and JavaScript.  
The game challenges users to match pairs of cards while enhancing memory and focus.

## Features

- Card flipping and matching logic  
- Multiple difficulty levels  
- Interactive and engaging gameplay  
- Responsive design for different screen sizes  
- Smooth animations for enhanced user experience  

## Technologies Used

- HTML  
- CSS  
- JavaScript  

## Description

This project enhanced my understanding of JavaScript logic, DOM manipulation, and building interactive web applications.
